# Padrão de README (repos públicos)

Todo repo público da org usa o mesmo esqueleto, baseado no README do Vision: **inglês primeiro, português logo abaixo no mesmo arquivo**, ligados por âncora. Complementa o `DUNGEON.md` ([PROJECT_PAGE_STANDARD.md](PROJECT_PAGE_STANDARD.md)): o `DUNGEON.md` alimenta o card da home; o README é a porta de entrada de quem abre o repo.

## Template

```md
# <Nome> · Dungeon Dev Labs

**English** · [Português](#português)

<Uma frase: o que é. Se o código não está no repo, diga aqui o que o repo contém.>

## What's here
<tabela `File | Purpose` ou lista curta do conteúdo do repo>

## Rules / How to contribute
<regras de formato, limites, como validar antes do push — só se houver>

## Privacy
[Privacy policy](<caminho em inglês>) · <link da Play Store, se for app>

## Community
<como reportar bug ou sugerir: Issues, e-mail de contato>

## AI
Built with AI dev copilots. Images generated by AI.

---

## Português

<mesma estrutura, mesmos títulos traduzidos>
(### nos subtítulos; "O que tem aqui", "Regras / Como contribuir", "Privacidade", "Comunidade", "IA")
```

## Regras
- Título sempre `# <Nome> · Dungeon Dev Labs`; a linha de idiomas vem logo depois.
- As duas línguas têm as **mesmas seções, na mesma ordem**; mudou uma, atualize a outra.
- Sempre ter as seções **Privacy** (se houver app publicado, o link é exigido pela Play Store) e **AI** (aviso de copilotos de IA e imagens geradas por IA, igual ao do site).
- Imagens em pixel art: `width` fixo (ex.: 96) e `alt` descritivo.
- Frases curtas; nada de seção vazia — omita a que não se aplica (exceto Privacy e AI).
- O texto de `summary_en`/`summary_pt` do `DUNGEON.md` deve bater com a frase de abertura do README.
